# Layout

> **미채택 JDC 관찰 자료**: 아래 색·치수·도메인·경로는 원본 관찰 시점의 근거입니다. 솔루션 공통 기본값으로 적용하지 않습니다.

> 원본 Figma: Aifrica Design System / `RP8QTyB9n2ZpgfCgmuXgsz` · node `6890:5216`

레이아웃(Layout)은 UI 구성 요소들이 어떻게 배치되고 정렬되는지에 대한 구조적 정의로, 화면 전반에 걸쳐
일관된 시각적 경험을 제공한다. 균일한 크기와 간격을 사용하여 다양한 플랫폼과 환경에서 디자인의 통합성을
유지한다.

## 원칙

- **12컬럼 기반** — Aifrica Design System 그리드는 12개 컬럼을 기본으로 한다. 12는 약수가 많아(1,2,3,4,6,12)
  다양한 span 분할(전체 12, 절반 6, 3분의1 4, 4분의1 3 …)이 가능하다.
- **일관된 간격** — gutter 와 margin 은 중단점 범위 내에서 고정값으로 유지되어, 어떤 화면 크기에서든
  동일한 리듬을 가진다.
- **목적에 맞는 타입 선택** — 콘텐츠 성격에 따라 Fluid(가변) 또는 Fixed(고정) 그리드를 선택한다.

## Grid anatomy (그리드 구성 요소)

그리드는 **컬럼(Column), 거터(Gutter), 마진(Margin)** 3가지 요소로 구성된다.

```
┌─Margin─┬────────────────────────────────────┬─Margin─┐
│        │ Col1  Col2  Col3 ... Col12         │        │
│ 24px   │  ↑Gutter(12px)  각 컬럼 간 간격     │ 24px   │
│        │ Column: 콘텐츠를 담는 세로 영역      │        │
└────────┴────────────────────────────────────┴────────┘
```

| 요소       | 역할         | 설명                                                                                                                                                    |
| ---------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Column** | 콘텐츠 영역  | 페이지를 일정한 수의 섹션(12개)으로 나누어 콘텐츠를 구성. 고정 그리드에서는 컬럼 너비가 고정값, 가변 그리드에서는 가변값으로 설정되어 화면 크기에 적응. |
| **Gutter** | 컬럼 간 간격 | 컬럼 사이의 여백으로 콘텐츠를 구분. 중단점 범위별로 고정값(기본 12px) 설정.                                                                             |
| **Margin** | 외부 여백    | 그리드의 양끝 여백. 콘텐츠가 시각적 영역 밖으로 벗어나는 것을 방지. 중단점 범위별로 고정값(기본 24px) 설정.                                             |

## Grid types (그리드 유형)

그리드 유형은 **Fluid(가변)** 와 **Fixed(고정)** 2가지로 나뉜다. 목적에 맞는 이상적인 그리드를 적용한다.

| 유형             | 특징                                                                                                                | 언제 사용?                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **Fluid** (가변) | 화면 너비에 따라 자동 확장. 주 콘텐츠 영역의 모든 가용 공간을 채움. 컬럼과 콘텐츠가 화면 크기에 맞춰 동적으로 조정. | 반응형 웹, 콘텐츠량이 유동적인 대시보드·목록                     |
| **Fixed** (고정) | 브라우저 창 크기에 관계없이 열 너비가 고정. 표준화된 디자인 유지.                                                   | 정밀한 정렬이 필요한 폼·설정 화면, 일관된 디자인이 중요한 페이지 |

### Fluid 구현 (CSS)

```css
/* 12컬럼 가변 그리드 — 컬럼 너비가 1fr 로 가변 */
.grid-fluid {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 12px; /* gutter */
}
```

### Fixed 구현 (CSS)

```css
/* 12컬럼 고정 그리드 — 컬럼 너비가 고정값 */
.grid-fixed {
  display: grid;
  grid-template-columns: repeat(12, 41px); /* 고정 컬럼 폭 */
  gap: 12px; /* gutter */
  justify-content: center; /* 남는 공간은 중앙 정렬 */
}
```

### 컬럼 span 사용 예

12컬럼 그리드에서 자식 요소의 `grid-column` 으로 span 을 지정한다.
Figma(node `6890:7000`)의 시각화는 5가지 분할을 보여준다.

| 분할  | span      | 블록 수 | 비고              |
| ----- | --------- | ------- | ----------------- |
| 전체  | `span 12` | 1       | 한 행을 전부 차지 |
| 2분할 | `span 6`  | 2       | 절반씩            |
| 3분할 | `span 4`  | 3       | 3분의 1씩         |
| 4분할 | `span 3`  | 4       | 4분의 1씩         |
| 6분할 | `span 2`  | 6       | 6분의 1씩         |

```css
/* 전체 너비 */
.col-full {
  grid-column: span 12;
}
/* 절반 (2열) */
.col-half {
  grid-column: span 6;
}
/* 3분의 1 (3열) */
.col-third {
  grid-column: span 4;
}
/* 4분의 1 (4열) */
.col-quarter {
  grid-column: span 3;
}
/* 6분의 1 (6열) */
.col-sixth {
  grid-column: span 2;
}
```

## 참조 방법

Layout 은 별도의 CSS 변수 토큰이 아니라, 위 CSS 패턴(`grid-template-columns`, `gap`)을
컴포넌트의 `*.css.ts` 에 직접 적용한다. Color/Typography 와 달리 변수화된 토큰은 없다.

| 환경                  | 사용법                                                                     |
| --------------------- | -------------------------------------------------------------------------- |
| **vanilla-extract**   | `display: 'grid'`, `gridTemplateColumns: 'repeat(12, 1fr)'`, `gap: '12px'` |
| **Tailwind 유틸리티** | `grid grid-cols-12 gap-3` (gap-3 = 12px)                                   |
| **일반 CSS**          | `display: grid; grid-template-columns: repeat(12, 1fr); gap: 12px`         |
