# Aifrica 팀 자산 적용

사용자의 현재 요청과 적용 범위의 저장소 지침을 따르고, 역할과 솔루션을 확인한다.
TeamAI docs mirror의 `common/README.md`, `common/resolution.md`에서 경로·적용 범위를 찾는다.
공용 원본에서는 `docs/common/`이 같은 위치다.

Git 작업은 common/git-docs의 원문과 common/github-project-guide.md를 읽는다.
문서화된 예시, 기술 스냅샷, 관찰한 특정 고객 설정을 현재 제품의 채택 사실로 간주하지 않는다.
현재 작업에 필요한 역할/솔루션만 읽고 다른 분야의 스킬을 강제로 적용하지 않는다.
