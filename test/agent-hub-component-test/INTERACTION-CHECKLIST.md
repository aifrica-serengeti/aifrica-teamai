# 상호작용 보완 점검표

React 테스트 앱에서 아래 순서로 확인할 수 있습니다. 공용 Menu의 상호작용을 계승하고,
이번에 채택한 fade·메시지 reveal·shimmer·halo 수치는 Figma 실측과 구분합니다.
실제 Agent Hub 제품에 연결할 때도 같은 항목을 반복해 주세요.

| 위치                          | 확인할 조작                                                        | 통과 기준                                                                                                                                                                                                                                                      |
| ----------------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 입력과 기본 요소 → Checkbox   | small/medium/large를 체크·해제하고 일부 선택↔체크를 빠르게 전환   | 표시 중간과 완료 때 Mark x/y·크기가 동일합니다. opacity만 바뀌고 Box·라벨·focus가 움직이지 않습니다.                                                                                                                                                           |
| 탐색과 콘텐츠 → 두 Picker     | 추천형과 검색형 행에 진입·이탈하고 ↑↓/Tab으로 이동                 | 두 형태 모두 행 배경이200ms로 전환됩니다. 키보드 focus는 행 안쪽 ring 한 개이며 hover 중 중복 ring이 없습니다. 모델·필터·더보기는 독립 focus를 유지합니다.                                                                                                     |
| 같은 화면 → Menu              | hover·키보드 이동·비활성 명령 확인                                 | 공용 Menu처럼 hover 배경과 키보드 inset ring을 구분합니다. focus된 행을 hover해도 바깥 outline이 추가되지 않고 이탈 시 내부 ring만 복귀합니다. 전역 focus CSS가 뒤에 있어도 동일하며 disabled는 실행되지 않습니다.                                             |
| 같은 화면 → Flyout            | ‘첨부파일 열기’의 ‘분석 자료’, 아래 독립 ‘파일 모음’을 펼치고 접기 | 두 예제 모두 자식이 실제로 나타나고 사라집니다. 본문 높이와 화살표가 전환되고 빠른 재토글에도 마지막 상태가 유지됩니다. 자식 focus에서 닫으면 부모로 복귀합니다.                                                                                               |
| 대화와 세션 → 예시 선택       | 예시 선택 직후 입력·한국어 IME 조합 시작                           | 원문 value는 즉시 완전 반영되고 좌→우 시각 reveal만 진행됩니다. 직접 편집·IME 시작 시 즉시 효과를 취소하고 caret·선택·복사를 유지합니다.                                                                                                                       |
| 같은 화면 → 사용자 메시지     | AI 본문 주입·AI 청크 추가·다른 본문으로 교체                       | 새 본문 또는 새 suffix만400ms로 나타납니다. 읽은 prefix를 다시 가리지 않고 빠른 교체 뒤 이전 문구가 돌아오지 않습니다. 별도 assistant renderer는 제품에서 같은 helper를 연결해 검증합니다.                                                                     |
| 같은 화면 → 생각 중 표시      | shimmer 켜기·끄기, 읽기 모드 비교                                  | 폭28%의 두 띠가 중심 간격50%로 흐릅니다. 정지 상태에는 고정된 뿌연 부분이 없고 로고·글자 위치는 고정됩니다.                                                                                                                                                    |
| 같은 화면 → 진행 단계         | active 파동을 여러 주기 관찰                                       | 파란 중심은 항상 고정됩니다. halo는 투명→서서히 표시→확산·소멸하며 루프 끝과 시작 모두 투명합니다.                                                                                                                                                             |
| 헤더와 내비게이션 → 예약 편집 | 빈도 popup 열기·방향키·Escape                                      | 마우스로 열기·hover 후 이탈에는 option ring이 없고 현재 값의 check만 유지됩니다. Enter/Space·Arrow/Home/End 탐색에서만 내부 ring·가상 focus가 표시됩니다. 짧은 목록은 추가 gutter0, 긴 목록은4px thumb·11px gutter를 유지하며 Escape는 Dialog를 닫지 않습니다. |
| 같은 화면 → SNB               | depth1/2 hover·선택·더보기 키보드 조작                             | 더보기 host가 행 오른쪽 끝에서2px 안쪽에 있습니다. 노출 전후 제목이 밀리지 않고 더보기가 행 선택·프로젝트 펼침을 함께 실행하지 않습니다.                                                                                                                       |

모든 효과는 동작 줄이기·강제 색상·인쇄에서 내용과 상태를 즉시 읽을 수 있어야 합니다.
반복 조작·화면 전환·unmount 후 이전 완료 처리나 숨은 focus 대상이 남지 않아야 합니다.

## 제품에 연결한 뒤 추가 확인

- 실제 API의 빠른 응답·청크 연속 수신·취소·메시지 교체에서 revision과 요청 ID가 맞는지 확인합니다.
- 한국어 IME, 여러 줄·긴 문구,200% 확대, 좁은 화면에서 줄바꿈·caret·마지막 행 가시성을 확인합니다.
- 키보드만으로 선택·펼침·닫기·Escape·Tab 복귀를 수행하고 실제 스크린리더로 이름·본문이 중복되거나 글자별로 반복 안내되지 않는지 확인합니다.
- 운영체제 동작 줄이기와 대상 브라우저에서 모션 세기·속도가 적절한지 확인합니다. 제품 테마의 focus 색과 대비도 비교합니다.

이 테스트 앱은 제품 API·전체 assistant 메시지 renderer·실제 제품 배포를 포함하지 않습니다.
