## 7. 상태별 아이콘 형태 (Icon Morphology)

각 상태는 고유한 아이콘 형태를 가진다. **모든 path 데이터는 Figma 원본 SVG 를 직접
fetch 한 값이다.** 20×20 viewBox 절대 좌표 기준.

### Error — 빨간 원 + 흰색 X

| 요소 | 형태                             | 데이터                                                        |
| ---- | -------------------------------- | ------------------------------------------------------------- |
| 원   | 채워진 원 r=8.335                | `<circle cx="10" cy="10" r="8.335" fill="--status-error"/>`   |
| X    | 두 개의 대각선 stroke 1.25 round | `d="M13.334 6.666 L6.666 13.334 M6.666 6.666 L13.334 13.334"` |

> X 의 렌더 원점은 Figma layout 역산 시 `(6.46, 6.46)`. 중앙 정렬을 위해 path 절대좌표를
> 직접 계산하여 적용(inset 35.42% + overflow -10.71% 역산).

### Warning — 노란 원 + 흰색 느낌표

| 요소              | 형태                     | 데이터                                                          |
| ----------------- | ------------------------ | --------------------------------------------------------------- |
| 원                | 채워진 원 r=8.335        | `<circle cx="10" cy="10" r="8.335" fill="--status-warning"/>`   |
| 느낌표 막대(stem) | 수직선 stroke 1.25 round | `d="M10 5.73 V9.88"`                                            |
| 느낌표 점(dot)    | 원 fill                  | `<circle cx="10" cy="12.4" r="0.775" fill="--status-on-fill"/>` |

### Success — 초록 원 + 흰색 체크

| 요소 | 형태                           | 데이터                                                        |
| ---- | ------------------------------ | ------------------------------------------------------------- |
| 원   | 채워진 원 r=8.335              | `<circle cx="10" cy="10" r="8.335" fill="--status-success"/>` |
| 체크 | 3점 polyline stroke 1.25 round | `d="M13.89 7.08 L8.55 12.43 L6.11 10.00"`                     |

> 체크 path 의 3개 꼭짓점(우상단/하단/중간좌)은 Figma Vector 의
> `inset 35.42%/30.54%/37.85%/30.57% + overflow -11.69%/-8.04%` 를 역산한 정확 좌표.

### Normal — 파란 테두리 원(투명 fill) + 파란 체크

| 요소 | 형태                                                      | 데이터                                                                                                                   |
| ---- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 원   | **실선** 테두리 원 r=7.708, **투명 fill**, primary stroke | `<circle cx="8.333" cy="8.333" r="7.708" fill="none" stroke="--status-primary" stroke-width="1.25"/>` (17×17 nested svg) |
| 체크 | 3점 polyline stroke 1.25 round                            | `d="M13.89 7.08 L8.55 12.43 L6.11 10.00"`                                                                                |

> **점선 아님(실선).** 색상은 neutral(회색)이 아니라 **primary(파랑)**.
> **fill 은 투명**(흰색이 아님) — 배경이 비치는 outline 아이콘이므로.

### In progress — 공용 Spinner

| 요소    | 형태          | 데이터                                       |
| ------- | ------------- | -------------------------------------------- |
| Spinner | 공용 컴포넌트 | `<Spinner size="small" aria-hidden="true"/>` |

### Incomplete — 파란 점선 원 + 좌측 절반 채움

| 요소                 | 형태                                       | 데이터                                                                                                                           |
| -------------------- | ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| 점선 원(아래층)      | stroke r=7.708, dasharray 보정값           | `<circle cx="10" cy="10" r="7.708" stroke="--status-primary" stroke-width="1.25" stroke-dasharray="1.6177 3.2256" fill="none"/>` |
| 좌측 반원 fill(위층) | 호 path, r=**8.333**(stroke 외곽까지 확장) | `d="M10 1.667 A 8.333 8.333 0 0 0 10 18.333 Z"`                                                                                  |

> **z-order 핵심:** 점선 원을 먼저 그리고, 좌측 반원 fill 을 위에 덮는다.
> 이래야 좌측 점선이 반원에 가려 보이지 않는다.
> 반원 반경은 stroke 외곽(7.708 + 0.625 = 8.333)까지 확장해야 점선을 완전히 덮는다.

### Not started — 회색 점선 원. 채움 없음

| 요소    | 형태                                      | 데이터                                                                                                                                        |
| ------- | ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 점선 원 | stroke r=7.708, neutral, dasharray 보정값 | `<circle cx="8.333" cy="8.333" r="7.708" stroke="--status-neutral" stroke-width="1.25" stroke-dasharray="1.6177 3.2256"/>` (17×17 nested svg) |

### Pending — 진회색 원 + 흰색 점 3개(가로)

| 요소   | 형태                                         | 데이터                                                        |
| ------ | -------------------------------------------- | ------------------------------------------------------------- |
| 원     | 채워진 원 r=8.335, **neutral(진회색)**       | `<circle cx="10" cy="10" r="8.335" fill="--status-neutral"/>` |
| 점 3개 | 원 fill, y=10, x=5.83/10/14.17 (간격 4.17px) | `<circle cx="5.83" cy="10" r="1.042"/>` × 3                   |

> **색상은 neutral(진회색 #757575)** — primary(파랑)가 아님. Not started 와 동일 색상.

### Info — 파란 원 + 흰색 i (dot + ⌐형 스템 + 하단 가로 발)

| 요소               | 형태                                | 데이터                                                                |
| ------------------ | ----------------------------------- | --------------------------------------------------------------------- |
| 원                 | 채워진 원 r=8.335                   | `<circle cx="10.005" cy="10.005" r="8.335" fill="--status-primary"/>` |
| dot                | 곡선 path fill (Figma 원본)         | `d="M10.0002 5.34863 C9.80859 5.34863 ... Z"`                         |
| stem(⌐형)          | stroke 1.25 round join              | `d="M9.03125 9.22461H10.194V13.4882"`                                 |
| foot(하단 가로 발) | stroke 1.25 **miterlimit 10** round | `d="M8.45117 13.876H11.9395"`                                         |

> **Info 는 단순한 소문자 'i' 가 아니다.** dot 은 곡선 path 이고, stem 은 ⌐ 형태이며,
> foot(하단 가로 발/serif)가 별도로 존재한다. foot 은 `stroke-miterlimit="10"` 이 필요.
> 반드시 Figma 내보내기 SVG 의 path 를 그대로 사용할 것.

## 9. 애니메이션

### 다크/라이트 모드 전환

아이콘 색상 및 Label 텍스트 색상 전환을 0.2초에 걸쳐 부드럽게 처리한다.
깜빡임 없이 전환되도록 색상 속성만 지정한다.

```css
/* State icon wrapper */
transition: color 0.2s ease;

/* Label */
transition: color 0.2s ease;
```

- **절대 `transition: all` 을 쓰지 않는다** — 레이아웃 속성에도 애니메이션이 걸려
  의도치 않은 동작이 발생한다. 색상 속성만 지정.
- 전역 `*` 셀렉터는 성능 저하/부작용으로 금지한다.

### In progress 회전

Spinner 컴포넌트(`size="small"`)가 자체적으로 `--spinner-speed`(기본 1s)로
시계 방향 무한 회전한다. Status 는 별도 회전 애니메이션을 정의하지 않는다.

> reduced-motion은 소비 앱의 실제 스타일에서 적용 여부를 확인한다. 전역 규칙이 있다고 가정하지 않는다.
> `@media (prefers-reduced-motion: reduce)`가 해당 요소에 적용되지 않으면 컴포넌트 범위의 전환·애니메이션을 즉시 완료하는 규칙을 둔다.
> 전환을 생략해도 값·focus·표시 여부와 종료·정리 책임은 유지한다.
