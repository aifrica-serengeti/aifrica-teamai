## 9. 접근성

| 항목             | 스펙                                                                                                                              |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 장식용 아이콘    | `aria-hidden="true"` 권장 (텍스트 라벨이 의미를 전달할 때)                                                                        |
| 의미 전달 아이콘 | `role="img"` + `aria-label="<아이콘 의미>"` 또는 `title`                                                                          |
| 키보드           | 아이콘 자체는 비상호작용. 버튼/링크 내에 배치 시 해당 요소의 포커스 링을 따름                                                     |
| 히트 영역        | 아이콘 단독 사용 시 최소 16px(m). 클릭 영역이 필요하면 8px 패딩 래퍼로 32×32 확보                                                 |
| 색상 대비        | 의미 전달 아이콘(error/warning/success)은 색상만으로 상태를 전달하지 않도록 형태로도 구분 (CircleX / TriangleAlert / CircleCheck) |

> **주의**: 상태 아이콘을 색맹 사용자에게 의존하지 말 것. error(빨강)와 success(초록)는
> 색맹에서 구분이 어려울 수 있으므로 형태(X / 체크)로도 구별되도록 lucide 매핑을 유지한다.

`grid` / `grid_off`를 IconButton에서 사용할 때 아이콘은 장식용으로 숨기고, 버튼의 접근성 이름은
현재 가능한 액션인 `격자 표시` 또는 `격자 숨기기`로 제공한다.
