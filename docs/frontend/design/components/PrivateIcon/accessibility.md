| 상황 | 사용법 |
| --- | --- |
| 텍스트로 이미 벤더·기술 이름을 표시함 | label 없이 사용한다. img는 alt 빈 문자열로 장식 처리된다. |
| 로고가 이름을 대신함 | label에 서비스 또는 기술 이름을 제공한다. |
| 클릭 가능한 요소 안의 보조 시각물 | PrivateIcon은 focus를 받지 않고 상위 Button 또는 Link가 accessible name을 제공한다. |

색상이나 로고 모양만으로 상태, 오류, 선택 여부를 전달하지 않는다. 상태는 Status, 텍스트 또는
적절한 시스템 아이콘으로 별도로 제공한다.
