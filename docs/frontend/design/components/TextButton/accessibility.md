## 10. 접근성

| 항목        | 스펙                                                                                 |
| ----------- | ------------------------------------------------------------------------------------ |
| 요소        | 네이티브 `<button>`. `type="button"` (기본값, 폼 제출 방지)                          |
| 키보드      | Tab 이동, Enter/Space 로 활성화                                                      |
| 포커스 표시 | `:focus-visible` 시 1px outline + 1px gap (색상: 라이트 `var(--accent-500)` / 다크 `var(--accent-400)`)  |
| 비활성      | `disabled` 속성 — 커서 `not-allowed`, 클릭 차단, 스크린리더 "사용 불가"              |
| 라벨        | 텍스트 라벨이 명확한 동사("더보기", "취소")여야 함. 아이콘-only 는 `aria-label` 필수 |
| 히트 영역   | 최소 Tiny 24×24. 모바일에서는 Small(28) 이상 권장                                    |
| 밑줄        | **금지** — Link 와 혼동. 텍스트 장식 없음                                            |
