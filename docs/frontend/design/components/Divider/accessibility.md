## 9. 접근성

| 항목   | 스펙                                                                                                                           |
| ------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 역할   | Radix `Separator` — `decorative`(기본)이면 `role` 없음, 의미론적 분리면 `aria-orientation` 노출                                |
| 키보드 | 비상호작용 요소 — 포커스 불가, 탭 순서에서 제외                                                                                |
| 대비   | 선 색 `#dddddd`는 배경 `#ffffff` 대비 약 1.4:1 (장식용 분리선이므로 WCAG 텍스트 대비 기준 비적용. 정보 전달 시 추가 라벨 권장) |
| 의미론 | 순수 장식 분리는 `decorative` prop 사용. 섹션 경계를 알리는 용도면 별도 heading/label로 의미 보강 권장                         |
