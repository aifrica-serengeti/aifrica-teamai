## 10. 접근성

| 항목               | 스펙                                                                                          |
| ------------------ | --------------------------------------------------------------------------------------------- |
| 요소               | Radix Avatar.Root(`span`). 이미지는 `Avatar.Image`(`img`), 이니셜은 `Avatar.Fallback`(`span`) |
| 이미지 대체 텍스트 | `Avatar.Image` 의 `alt` 속성 필수. 스크린리더가 사용자명을 읽는다                             |
| Fallback           | 이미지 없을 때 이니셜(1문자) 표시. alt 가 없으면 스크린리더가 이니셜을 읽는다                 |
| 비활성             | 의미적 표시만. `data-disabled` 속성. 실제 상호작용 차단은 부모에서 처리                       |
| 히트 영역          | 최소 16×16(size 16). 터치 대상이 필요하면 24px(size 24, 표준) 이상 권장                       |

> Avatar 자체는 링크/버튼이 아니므로 포커스를 받지 않는다. 프로필로 이동하는 용도라면
> Avatar를 `<a>` 또는 `<button>` 으로 감싸고 별도의 접근성 라벨을 제공한다.
