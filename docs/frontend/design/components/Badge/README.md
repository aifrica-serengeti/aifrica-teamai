## 1. 개요

특정 요소의 상태나 새로운 알림에 대한 빠른 시각적 인식을 돕기 위한 요소. 주로 아이콘
버튼·아바타·탭 등 다른 요소의 우상단에 겹쳐 배치하여 읽지 않은 알림이나 항목 수를 표시한다.

**매트릭스:** 2 variant(Dot / Counter) × 캡핑 동작(99+). Badge 는 단일 point 색상만
사용하며 별도의 size/상태 매트릭스는 없다.

**기술 기반:** 네이티브 `<span>` 요소를 기반으로 vanilla-extract `.css.ts` 로
스펙을 직접 렌더한다. shadcn/Radix primitive 없이 순수 CSS 로 렌더한다(Badge 는 단순
도형/숫자이므로 primitive 가 불필요).

### Variant 역할 (사용 가이드)

| Variant     | 용도                          | 설명                                                          |
| ----------- | ----------------------------- | ------------------------------------------------------------- |
| **Dot**     | 단순 알림 및 새로운 정보 표시 | 읽지 않은 알림이 있다는 사실만 전달. 수량 미표시              |
| **Counter** | 알림 수 표시                  | 항목 수 정보를 전달하는 숫자 라벨 포함. 99 초과 시 "99+" 캡핑 |

> **용도 구분**: Dot 은 "새로운 것이 있다"는 사실만, Counter 는 "몇 개 있는지"까지
> 전달할 때 사용한다. 수량이 중요하지 않다면 Dot 을 우선한다(시각적 노이즈 최소화).
