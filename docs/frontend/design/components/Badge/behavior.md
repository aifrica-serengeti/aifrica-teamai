## 7. 상태 (Behavior)

Badge 자체는 비활성(disabled)/읽기 전용(read-only) 등의 상태를 가지지 않는다.
대신 **count 값에 따른 조건부 렌더링** 과 **99+ 캡핑** 이 핵심 동작이다.

| 동작            | 조건                            | 결과                                                               |
| --------------- | ------------------------------- | ------------------------------------------------------------------ |
| **렌더링 생략** | Counter variant 의 `count <= 0` | Badge 를 렌더하지 않음(`null` 반환). 알림이 없으면 표시하지 않는다 |
| **숫자 표시**   | `1 <= count <= max`             | `count` 를 그대로 표시                                             |
| **99+ 캡핑**    | `count > max` (기본 max=99)     | `"{max}+"` 표시 (예: "99+")                                        |
| **Dot**         | 항상                            | count 와 무관하게 항상 원형만 렌더                                 |

> **행동 규칙**: 최대 99까지 표시되며, 그 이상은 "99+"로 처리된다. `max` prop 으로
> 캡핑 임계값을 조정할 수 있다(예: `max={999}` → "999+"). 캡핑 여부는 `data-capped`
> 속성으로 노출되어 필요시 스타일 분기에 사용할 수 있다.

## 9. 애니메이션

### 다크/라이트 모드 전환

배경·텍스트 색상 전환을 0.2초에 걸쳐 부드럽게 처리한다. 깜빡임 없이 전환되도록
색상 속성만 지정한다.

```css
/* Dot */
transition: background-color 0.2s ease;

/* Counter */
transition:
  background-color 0.2s ease,
  color 0.2s ease;
```

- **절대 `transition: all` 을 쓰지 않는다** — 레이아웃 속성(width/height)에도 애니메이션이
  걸려 숫자가 바뀔 때 박스 크기 변화가 튀는 현상이 생긴다. 색상 속성만 지정.
- 전역 `*` 셀렉터는 성능 저하/부작용으로 금지한다(AGENTS.md "색상 전환 애니메이션" 참조).

> `globals.css` 의 `@media (prefers-reduced-motion: reduce)` 가 모든 transition 을
> 무력화하므로 컴포넌트는 별도 reduced-motion 처리 불필요.
