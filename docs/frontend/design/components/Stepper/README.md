# Stepper

> **추출 참조 계약(reference-contract)**: 원본의 상세 API·상태·접근성·예제를 보존한 문서입니다.
> 이 저장소에 실행 컴포넌트가 있다는 뜻이 아닙니다. 수치·중립색·글꼴은 추출 baseline이며,
> [계약 수준과 솔루션 매핑](../../contract-levels.md)을 먼저 적용하고 대상 솔루션의 실제 구현·버전을 확인합니다.

이 문서는 **의존 문서와 함께** Stepper 컴포넌트를 상세 상태·시각 계약을 구현하기 위한
완전한 스펙이다. 이 디렉터리와 의존 문서로 계약을 확인하고 솔루션 mapping·자산을 추가해야 한다.

---

> 문서 분할 안내: 기존 가이드의 “이 파일” 표현은 이제 이 디렉터리의 문서 묶음 전체를 뜻한다.
> 원문 내용은 삭제하지 않고 목적별 문서로 나눴다.

## 1. 개요

다단계 프로세스의 진행 상태를 표시하는 네비게이션 컴포넌트다. 주문·가입·설정 마법사 등
순차적 단계가 있는 화면에서 사용자가 현재 위치를 파악하고 남은 단계를 예측할 수 있게 한다.

**기술 기반**: 순수 React + vanilla-extract. Radix UI / shadcn 미사용. 체크·X 마크는
직접 인라인 SVG로 렌더한다.
