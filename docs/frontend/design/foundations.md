# UI foundations

> **추출 참조 계약(reference-contract)**: 원본의 상세 API·상태·접근성·예제를 보존한 문서입니다.
> 이 저장소에 실행 컴포넌트가 있다는 뜻이 아닙니다. 수치·중립색·글꼴은 추출 baseline이며,
> [계약 수준과 솔루션 매핑](contract-levels.md)을 먼저 적용하고 대상 솔루션의 실제 구현·버전을 확인합니다.

이 문서는 Aifrica Design System의 공통 토큰과 레이아웃 규칙의 단일 진입점이다.
각 foundation의 전체 색상값, CSS 변수, 그림자, 타이포그래피, 그리드 구현 예시는 아래
문서에 보존되어 있다.

- [Color](./foundations/Color.md)
- [Elevation](./foundations/Elevation.md)
- [Typography](./foundations/Typography.md)
- [Layout](./foundations/Layout.md)

새 프로젝트 재현에서는 이 네 문서를 먼저 적용한 뒤 [재현 프로토콜](./reproduction.md)과
대상 [컴포넌트 가이드](./components/index.md)를 읽는다.
