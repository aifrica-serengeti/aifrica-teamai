# Backend 확장 경계

backend 역할은 현재 회사 공통 문서·Git 규약과 선택한 솔루션의 컨텍스트를 받는다.
backend 전용 스킬과 아키텍처 계약은 아직 수집·검증하지 않았다.

backend 팀이 합의한 계약을 추가할 때 `skills/backend/<skill-name>/SKILL.md`,
`rules/backend/`, 이 문서 디렉터리를 사용하고 `manifest/roles.yaml`의 backend 리소스에
`skills: [backend]`를 추가한다. frontend 스킬을 backend에 재사용한 것으로 표시하지 않는다.
