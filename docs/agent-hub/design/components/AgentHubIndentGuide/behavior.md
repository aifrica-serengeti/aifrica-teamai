# AgentHubIndentGuide — 동작과 상태 소유권

[문서 인덱스](./README.md) · [Figma 관찰 기록](../../references/file-code-refresh.figma.json)

가이드는 자체 이벤트·포커스·타이머를 만들지 않습니다. 편집기 또는 현재 블록 owner가 각 줄의 active 여부를 공급합니다.
코드를 표시만 하는 Viewer는 기본 선으로 렌더할 수 있으며 가이드에 클릭으로 커서를 옮기는 기능을 붙이지 않습니다.

연속 행은 같은 가이드 폭과 줄 높이를 사용합니다. 접힌 코드 줄 제거·문서 교체 시 가이드도 해당 줄과 함께 정리합니다.
Figma에서 전환 시간은 확인하지 않았습니다. 정적 선에 반복 pulse·shimmer를 새로 추가하지 않습니다.
