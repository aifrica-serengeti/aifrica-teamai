# AgentHubThumbnail — 접근성

아래는 제품 구현 의무이며 원본 Figma가 ARIA 동작을 제공한 것은 아닙니다.

- 설명에 필요한 사진은 의미 있는 `alt`를 받고, 인접 제목과 완전히 같은 정보인 장식 이미지는 빈 alt를 사용합니다.
- 색상·사진만으로 필수 상태나 파일 유형을 전달하지 않습니다. 필요한 텍스트는 상위 카드에서 제공합니다.
- 표시 전용 image에 button role·Tab index를 부여하지 않습니다. 실제 실행은 상위 native link/button을 사용합니다.
- 이미지 미제공/실패 시에도 상위 카드 이름과 실행 경로가 사라지지 않아야 합니다.
- crop 때문에 중요한 문자·도표가 사라지는 경우 contain이나 원본 보기 등 제품에 맞는 대안을 제공합니다.

이미지를 background-image로만 그리면서 대체 텍스트가 필요한 사진을 숨기지 않습니다.
인접 텍스트가 이미 의미를 모두 제공하는 경우 같은 이름을 image와 host에서 중복 낭독하지 않습니다.
