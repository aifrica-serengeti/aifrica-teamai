# AgentHubBreadcrumb — 접근성

공용 Breadcrumb의 내비게이션 의미·현재 위치·키보드·축약 접근성을 시각 확장 후에도 유지합니다.

- `nav`에 제품에 맞는 Breadcrumb 이름을 제공하고 상위 경로는 실제 href 또는 기존 router Link로 연결합니다.
- 현재 위치는 링크가 아닌 텍스트와 `aria-current="page"`로 노출합니다. 상위 경로와 같은 #1C1C1C라는 이유로
  현재 위치를 클릭 가능하게 만들거나 의미를 제거하지 않습니다.
- 구분자는 장식으로 숨기고 독립 이름·tab stop·클릭 동작을 만들지 않습니다. arrow SVG도 `aria-hidden` 또는 동등한 처리로 중복 읽기를 막습니다.
- 상위 경로는 Tab·Enter 이동과 공용의1px focus outline·offset1px를 유지합니다.
  Figma에 focus가 없어도 제거하지 않으며 root의 잘림·좁은 높이 때문에 링이 가려지지 않는지 확인합니다.
- 축약을 채택하면 개수를 포함한 펼치기 버튼 이름과 실제 Menu의 키보드·Escape·focus 복원 계약을 유지합니다.
  숨긴 중간 경로는 원래 순서로 탐색·이동할 수 있어야 합니다.
- 동일 색상·굵기만으로 현재 위치가 충분히 구분된다고 보증하지 않습니다. 실제 문맥·읽기 순서·접근성 상태를 확인하고
  추가 시각 구분이 필요하면 제품의 채택 근거를 남깁니다.
- 긴 라벨·번역·200% 확대에서 현재 위치와 경로 복구 수단이 가려지지 않는지 확인합니다.
  정적 샘플 폭이나 다섯 항목을 타깃 크기·반응형·접근성 통과의 근거로 쓰지 않습니다.

이번 확인은 Light mode 두 구성의 정적 모양입니다. 실제 router 이동·보조 기술·focus·메뉴 동작은 소비 제품에서 검증합니다.
