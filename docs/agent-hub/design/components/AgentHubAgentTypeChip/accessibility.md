# AgentHubAgentTypeChip — 접근성

공용 Chip의 정보 표시 의미를 유지합니다. 일반 텍스트 `span`으로 읽을 수 있어야 하며 Chip 자체는
Tab 순서에 넣지 않습니다. `role="button"`, `aria-pressed`, 선택 이벤트를 표시용 Chip에 부여하지 않습니다.
유형을 색만으로 전달하지 않고 어시스턴트·워크플로우·런타임·일반 채팅이라는 텍스트를 함께 제공합니다.

텍스트가 시각적으로 잘려도 전체 유형 이름은 접근성 트리에 남겨 둡니다. 제품에서 라벨을 바꾸거나 번역하면
HUG와 고정 폭의 차이, 확대 시 읽기 가능 여부를 확인합니다. tooltip만으로 유형 정보를 제공하지 않습니다.

assistant의 #3B82F6 글자와 #EBF3FF 배경은 불투명 sRGB 값 기준 대비가 약 3.29:1입니다.
12px 텍스트의 접근성 충족을 보증할 수 없습니다. 원본 색상은 참조 기록으로 보존하고 제품 채택 시
대비를 검증해 필요한 디자인 조정을 기록합니다. 공용 문서의 대비 보증 문구를 그대로 상속하지 않습니다.
다른 유형도 실제 제품의 폰트·surface·확대 조건에서 확인합니다.

제품이 disabled 표현이나 제거 기능을 추가한다면 공용 Chip의 `aria-disabled`, 실제 버튼 disabled·Tab 제외·
활성화 차단·focus-visible 계약을 유지합니다. 해당 상태의 시각 값은 이 Figma 노드에서 확인되지 않았습니다.
