# AgentHubFlyoutFooter

Flyout 하단에 설명 문구를 표시하는 비대화형 부품입니다. [상위 적용 조건](../../README.md)을 따릅니다.
독립 원본과 shell 안의 실제 override를 구분하며, 기존 구현이 없으면 [구현 안내](./implementation.md)에 따라 소비 제품에 새 export를 만들 수 있습니다.
직접 의존 컴포넌트는 없습니다. MenuLabel·TooltipFooter·Button·kbd 등의 원본 재사용이나 동작을 추가하지 않습니다.
실제 제품 source/export는 `unmapped`, 공유 채택 설정은 `draft`입니다.
