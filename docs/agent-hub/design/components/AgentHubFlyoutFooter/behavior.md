# AgentHubFlyoutFooter — 문구와 표시

Footer는 제품이 제공한 설명 문구를 평문으로 표시합니다. 원본의 치타 플랫폼 문구나 shell의 `meta`를 운영 문구로 고정하지 않습니다.
이 문장만으로 볼륨 권한·연결 가능 여부·관리 화면·route·버튼을 구현하지 않습니다.
실제 정책과 설명 문자열은 제품이 확인해 제공하고, 권한 차단은 해당 기능의 실행 owner가 처리합니다.

표시 여부는 Flyout owner가 관리합니다. 관찰한 visible binding과 footer=true 표현을 참고하되 상위 전체 property 정의가
미수집 상태임을 유지합니다. false 구성의 높이·아이템 개수·닫힘 결과를 이번 Figma에서 검증한 것으로 쓰지 않습니다.

Footer 자체에 click·키보드 탐색·자동 닫힘·전역 단축키·별도 비동기 요청을 넣지 않습니다.
본문이나 count 변경마다 자동으로 status/live region을 공지하지 않습니다.
실제 이름·설명 관계와 공지 빈도는 부모의 역할과 제품 흐름에 맞춰 정합니다.

Footer 문구가 길어져 높이가 바뀌면 부모가 리스트 공간과 하단 겹침을 조정합니다.
원본 absolute y365를 복사하는 것만으로 모든 항목의 scroll·focus 가시성이 확보되지는 않습니다.
Footer를 감추는 제품 구성은 상위가 조건부로 제거하고, 설명 id를 참조하고 있다면 그 연결도 함께 맞춥니다.
