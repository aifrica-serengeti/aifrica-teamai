# AgentHubPillChip — 상태와 동작

확인한 것은 다섯 상태의 모양입니다. Figma state를 앱의 선택 값·검색 조건·버튼 API로 곧바로 연결하지 않습니다.
공용 Chip처럼 정보만 보여 주는 용도라면 일반 텍스트로 남기고, hover·pressed 샘플이 있다는 이유만으로
click·toggle·Tab 이동을 추가하지 않습니다.

실제 제품이 이 pill을 조작 컨트롤로 사용한다면 먼저 동작의 목적과 상태 소유권을 확인합니다.
선택 값은 기존 호출자가 소유하며, 단순 액션·단일 선택·다중 선택·필터 적용 중 어느 의미인지 명시한 뒤
그 의미에 맞는 기존 primitive와 키보드 처리를 연결합니다. 하나의 조작이 중복 변경·검색을 발생시키지 않아야 합니다.

selected는 현재 enabled와 시각 값이 같습니다. 외형이 같아도 실제 선택 상태를 지우거나,
hover·pressed를 지속적인 선택 상태로 저장하지 않습니다. 선택 기능이 있다면 같은 외형이 사용자에게 충분한지
제품에서 확인하고 필요 조정의 근거를 남깁니다. 이번 정적 원본만으로 선택 기능의 구현 완료를 선언하지 않습니다.

원본 `disalbed`를 제품의 disabled 상태로 매핑할 경우 색상뿐 아니라 실제 클릭·키보드·변경 통지를 차단합니다.
오타를 그대로 앱 상태 이름으로 전파하거나 enabled·selected와 같은 배경이라는 이유로 활성화하지 않습니다.
hover·pressed 표현도 실제 disabled 위에 적용하지 않습니다.

이 노드에는 아이콘·제거 기능이 없습니다. `Show icon` 기본값 true만으로 이를 만들어 넣지 않습니다.
향후 기능이 필요하면 별도 근거와 의미·상태·접근성 계약을 확인합니다. 모션·dark·focus-visible·로딩도 미확인 범위입니다.
