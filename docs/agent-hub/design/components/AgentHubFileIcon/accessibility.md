# AgentHubFileIcon — 접근성

파일명·확장자·유형 텍스트와 함께 표시하면 아이콘은 장식으로 둡니다.
아이콘이 유일한 유형 정보라면 ‘PDF 파일’처럼 의미를 제공하되 실제 파일명과 중복 낭독하지 않습니다.
파일 유형은 색만으로 전달하지 않습니다.

아이콘 자체는 focus를 받지 않습니다. 다운로드·열기·삭제는 이름이 있는 링크나 버튼을 사용하고
제품의 keyboard·focus·disabled 처리를 따릅니다. 44px 타일 크기가 컨트롤의 hit area를 자동 보장하지는 않습니다.
이미지 차단·깨짐에서도 파일명과 동작을 사용할 수 있어야 합니다.
