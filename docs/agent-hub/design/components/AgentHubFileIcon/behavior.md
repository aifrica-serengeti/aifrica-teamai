# AgentHubFileIcon — 동작

파일 유형 판별은 제품의 adapter가 담당하고 이 컴포넌트는 결정된 type만 표시합니다.
MIME·확장자 우선순위, 코드 파일의 범위, MIME과 확장자가 다른 경우의 처리는 Figma에서 정의하지 않았습니다.
현재 제품의 업로드·첨부 계약을 확인해 정합니다. 표현용 분류를 업로드 허용 여부나 파일 검증에 사용하지 않습니다.

미지원·누락 type은 임의로 spreadsheet으로 바꾸지 않습니다. 제품에서 일반 document 자산을 fallback으로
채택할 수 있지만 ‘알 수 없는 파일’이라는 텍스트 의미는 유지합니다. 이 fallback은 제안이며 Figma variant가 아닙니다.
이미지 로딩 실패 시에도 파일명·유형 텍스트와 버튼 동작은 남아야 합니다.
로딩·선택·오류·삭제·다운로드 상태를 타일 내부에 숨기지 않고 목록 또는 컨트롤에서 관리합니다.
