# AgentHubFileIcon

업로드·첨부·파일 목록에서 같은 파일 유형을 같은 모습으로 표시하는 Agent Hub 재사용 계약입니다.
공용 system Icon에 배경만 더한 것이 아니라 전체 타일 SVG를 사용합니다.
적용 조건은 [상위 안내](../../README.md)를 따릅니다. 직접 공용 컴포넌트 의존성은 없습니다.
