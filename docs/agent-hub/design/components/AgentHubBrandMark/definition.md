# AgentHubBrandMark — 정의

사용자가 지정한 메인 화면 마크 노드 `2611:74300`의 이미지 자산입니다.
Figma 노드 이름은 `image 14533`, 타입은 Rectangle이고 표시 크기는180×180px입니다.
연결된 원본은 투명 PNG2048×2048이며 [원본 manifest](../../asset-manifest.json)의 Figma image hash와 일치합니다.
원본은 원형들이 한 장에 합성된 래스터 이미지입니다. 추가로 제공된 SVG도 같은 PNG를 `image` 요소에 넣은 파일이며
원형별 벡터 레이어를 제공하지 않습니다.

## 현재 표시 계약

원본 PNG의 픽셀·투명도·방향과1:1 비율을 유지하는 정적 이미지입니다. 사용자 요청으로 브랜드 마크 애니메이션을 제외했습니다.
공개 입력은 size·label·className·style이며 모션·재생 제어를 제공하지 않습니다.
원본 src는 Agent Hub 자산으로 연결하고 사용자 업로드 이미지·회사 공용 로고·다른 솔루션의 기본 마크와 혼용하지 않습니다.

기존 이미지 컴포넌트가 원본 비율·예약 크기·접근성 의미를 지원하면 재사용합니다. 직접 공용 컴포넌트 의존성은 없으며,
공유 registry의 실제 제품 source/export는 검증 전까지 `unmapped`입니다.

## 보존하는 복원 기록

분리 원본이 없어 PNG를 기준으로 작성했던 [복원 SVG](../../assets/brand/agent-hub-mark-layered.svg)는 비교 자료로 보존합니다.
타원의 윤곽·기울기·그라데이션과 겹침 아래 가려진 영역은 추정값입니다. Figma에서 받은 벡터 원본·원래 레이어의 정확한 복구·
픽셀 단위 동일 자산으로 표시하지 않습니다. 현재 표시 자산은 계속 원본 PNG이며 [복원 근거](./reconstruction.md)를 구분합니다.
