# AgentHubBrandMark — 동작

정적 원본 PNG를 표시합니다. 사용자 요청에 따라 브랜드 마크 애니메이션과 재생 제어를 제외했습니다.
마크를 로딩·녹음·AI 진행률·요청 완료 신호로 해석하거나 회전·광택·호흡 효과를 자동 추가하지 않습니다.
ThinkingStatus에서도 마크는 정적이며 글자의 별도 상태 표현과 분리합니다.

size는 예약 공간만 정하고 표시 비율은1:1을 유지합니다. 원본 로드 실패 시 예약 공간을 유지하고
인접 제품명·제목이 의미를 전달하도록 합니다. 파일 오류를 이유로 비교용 복원 SVG나 임의 도형으로 바꾸지 않습니다.

마크 자체는 버튼이나 링크가 아닙니다. 홈 이동이 필요하면 호출부가 링크 의미와 이동 목적을 알려 주는 이름을 소유합니다.
