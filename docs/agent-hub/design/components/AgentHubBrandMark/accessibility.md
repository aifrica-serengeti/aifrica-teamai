# AgentHubBrandMark — 접근성

옆에 같은 의미의 제품명·제목이 있으면 장식 이미지로 처리합니다. 마크만 제품을 식별하면 ‘Agent Hub’처럼 의미를 제공합니다.
파일명이나 ‘image 14533’을 읽게 하지 않습니다. 링크 안에서 유일한 콘텐츠라면 링크 이름이 이동 목적을 알려야 합니다.
장식 이미지 자체에 tab stop이나 버튼 역할을 부여하지 않습니다.

label이 비어 있으면 원본 PNG에 `alt=""`를 사용하고 의미가 있으면 label을 alt로 연결합니다.
같은 마크에 host·내부 이미지 이름을 중복하지 않습니다. 마크는 정적 이미지이므로 `progressbar`·`status`·live region을 추가하지 않습니다.

사용자 요청으로 브랜드 마크 애니메이션과 재생 제어를 제외했습니다. 동작 줄이기·강제 색상·인쇄에서도
같은 정적 원본과 예약 공간·접근성 의미를 유지합니다. 이미지가 차단돼도 인접 텍스트로 제품명과 주요 작업을 이해할 수 있어야 합니다.
