# AgentHubBrandMark — 스타일

기준 표시 크기는180×180px, 원본 비율은1:1입니다. 명시적인 width/height 또는 같은 비율의 예약 공간을 두고
`object-fit: contain`으로 원본 PNG를 표시합니다. 반응형에서도 비율을 보존하며 공용 Icon의16/20/24px scale이나
stroke 규칙을 일괄 적용하지 않습니다. 다크용 별도 마크·최소 허용 크기·clear space·워드마크 조합은 원본 노드에서 확인되지 않았습니다.

원본 PNG의 청록·파랑·보라 그라데이션과 투명 영역·방향을 그대로 유지합니다. 원본을 덮어쓰거나
색상 filter·임의 crop·회전·scale animation·추가 광택을 적용하지 않습니다. Figma screenshot의 회색 `#E6E6E6`은
상위 frame 배경이며 로고 자체의 배경색이 아닙니다.

사용자 요청으로 브랜드 마크 애니메이션을 제외했습니다. 모션 수치나 재생 상태를 연결하지 않으며,
기존 복원 SVG는 [비교 자료](./reconstruction.md)로만 보존합니다.
