# AgentHubFlyoutHeader — 정의

원본 `3005:23089`는 `flyout/header` 단일 COMPONENT입니다. title-group 안의 제목·count와 그 아래 설명으로 구성됩니다.
제목·개수·설명은 모두 일반 텍스트입니다. count를 Badge·Button·필터나 선택 상태로 바꾸지 않습니다.

| 실제 Figma TEXT 속성 | 기본 문자열 | 역할 |
| --- | --- | --- |
| `title#3005:0` | 첨부파일 | 제목 |
| `count#3005:1` | 11 | 개수 표시용 문자열 |
| `meta#3005:2` | 이 대화에 첨부한 파일입니다. | 설명 |

count는 숫자 타입이나 서버의 총 개수 계약이 아닌 TEXT입니다. 실제 전체 개수·현재 표시 개수·형식·locale은 제품이 결정합니다.
기본값11을 목록 길이·페이지 크기·상한으로 사용하지 않습니다.

Flyout 내부 `2975:76707`은 같은 원본 `3005:23089`를 재사용하며 폭을278px로 맞춥니다.
실제 인스턴스 값은 `title`, `count`, `meta`라는 샘플 문자열이고 해당 TEXT 속성 참조가 유지됩니다.
독립 원본의 문구와 인스턴스 override를 구분하고 제품 데이터로 연결합니다.

직접 의존 컴포넌트는 없습니다. 원본에는 클릭·검색·닫기·정렬·접기 동작이나 action slot이 없습니다.
상위 Flyout 전체 property 정의는 read-only getter 제한으로 수집하지 못했으므로,
Header의 확인된 TEXT 속성을 상위 전체 API나 상위에 속성이 없다는 근거로 확대하지 않습니다.
