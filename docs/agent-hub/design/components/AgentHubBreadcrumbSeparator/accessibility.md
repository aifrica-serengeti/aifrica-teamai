# AgentHubBreadcrumbSeparator — 접근성

공용 Breadcrumb와 같이 구분자는 장식입니다. 텍스트나 SVG를 `aria-hidden` 또는 동등한 방식으로 숨겨
경로 이름 사이에 slash·dash·arrow가 불필요하게 읽히지 않도록 합니다.

- 독립 button/link 역할·aria-current·tab stop·클릭 처리를 만들지 않습니다.
- SVG나 이미지로 넣어도 중복 이름을 주지 않습니다. 이미지라면 장식용 빈 alt 등 제품의 기존 방식을 사용합니다.
- 화면의 `Current` 판단과 nav 이름·링크 이름은 부모 Breadcrumb가 소유합니다.
  arrow 방향이나 구분자 색상만으로 현재 위치를 전달하지 않습니다.
- 구분자와 여백이 인접 링크의 focus-visible 표시를 가리거나 전체 경로의 폭 계산을 왜곡하지 않는지 확인합니다.
- 긴 라벨·확대·번역에서 경로가 줄거나 축약돼도 숨긴 경로의 복구 수단과 현재 위치를 유지합니다.

구분자는 조작 대상이 아니므로24px 높이를 버튼 타깃 크기 충족의 근거로 쓰지 않습니다.
실제 nav·링크·메뉴의 키보드·보조 기술 검증은 소비 제품에서 별도로 수행합니다.
