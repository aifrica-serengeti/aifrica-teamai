# AgentHubUserMessage — 접근성

- 사용자 메시지라는 발화자 정보를 제품의 대화 문맥·이름과 연결합니다. 눈에 보이는 avatar·timestamp를 새로 만들 필요는 없지만
  버블 색상·오른쪽 정렬만으로 발화자를 전달하지 않습니다. 필요하면 화면에 숨긴 발화자 이름을 사용합니다.
- 본문은 읽을 수 있는 평문이며 텍스트 선택·복사를 막지 않습니다. 버블 전체를 button·tab stop으로 만들거나 문장마다 focus를 추가하지 않습니다.
- 일반 Chip과 에이전트 이름은 정보 표시입니다. 라벨이 잘려도 전체 이름을 유지하고 제거·toggle·선택 동작을 추가하지 않습니다.
  Divider와 schedule 시계는 장식으로 숨겨 이름을 중복 읽지 않게 합니다.
- schedule의 상태 문구가 의미를 전달합니다. 시계 색이나 도형만으로 예약 경로·전송 상태를 알리지 않습니다.
- 숨겨진 description과 arrow는 읽기 트리·tab 순서·클릭 대상으로 복원하지 않습니다. Figma 노드 이름을 action 이름으로 쓰지 않습니다.
- 정적 메시지마다 `role="alert"`·별도 live region을 추가하지 않습니다. 대화 영역에 새 항목·동적 상태를 알리는 정책이 있으면
  그 소유자 한 곳에서 처리하고 같은 내용을 버블·상태 행·부모가 중복 낭독하지 않게 합니다.
- 메시지 도착·상태 갱신 때문에 사용자의 focus를 이동하지 않습니다. 대화 영역의 스크롤·읽던 위치·이동 수단은 기존 제품 계약이 소유합니다.
- 긴 본문·URL·번역·200% 확대에서 내용이 잘리거나 메타데이터가 본문을 가리지 않는지 확인합니다.
  줄바꿈·시각적 재배치를 채택해도 읽기 순서와 전체 내용은 유지합니다.

Light mode 세 샘플은 실제 보조 기술·대비·좁은 폭·동적 안내를 검증한 증거가 아닙니다.
표시만 하는 메시지에 기존 IconButton의 키보드·focus 계약을 무조건 추가하지 않습니다.
