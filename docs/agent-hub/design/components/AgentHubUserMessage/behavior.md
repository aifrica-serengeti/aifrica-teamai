# AgentHubUserMessage — 상태와 제품 연결

`kind`는 사용자 발화의 표시 형식입니다. chat을 sending, agent를 streaming, schedule을 성공 완료처럼 변환하지 않습니다.
실제 요청 상태·메시지 저장·예약 실행·응답 수명은 제품의 메시지/요청 owner가 관리합니다.
이 표시 컴포넌트가 송신·재시도·피드백 API를 호출하거나 응답 내용을 생성하지 않습니다.

본문은 전달받은 문자열을 평문으로 표시하고 사용자의 텍스트 선택·복사를 유지합니다.
Figma에 Markdown·HTML renderer는 없습니다. 문자열의 태그·기호를 실행하거나 Markdown을 확인된 기능으로 추가하지 않습니다.
공백·줄바꿈을 어떻게 보존할지 제품에서 명시하고 본문을 임의로 trim·축약·삭제하지 않습니다.

agent에서는 실제 지정한 에이전트 이름과 유형 표시 라벨을 연결합니다. 라벨 ‘에이전트’와 보라색만으로
업무 유형을 workflow로 판정하지 않습니다. 별도 상태를 메타데이터 텍스트나 숨김 description에 넣지 않습니다.

schedule의 ‘예약된 작업으로 전송됨’은 해당 전송 경로를 설명하는 샘플 문구입니다.
예약 실행 성공·응답 완료·모든 일반 메시지의 전달 완료를 보증하지 않습니다. 실제 상태 문구는 제품의 값·locale에 맞게 연결합니다.
예약/전송 상태가 갱신되더라도 기존 메시지 본문과 발화자·메타데이터를 임의로 초기화하지 않습니다.

본문이 길어지면 내용을 보존하면서 줄바꿈·높이 증가·긴 토큰의 읽기 방법을 제품 정책으로 연결합니다.
한 줄 샘플의 FIXED44·clipping을 전체 메시지에 강제하지 않습니다. 에이전트 메타데이터와 긴 본문의 좁은 폭 배치도 별도 검증합니다.

아바타·시간·복사 버튼·반응·재시도·assistant 응답·자동 스크롤은 이번 구조에 없습니다.
화면에서 필요하면 기존 계약과 제품 근거를 별도로 확인하고 이 컴포넌트의 검증 범위를 확대하지 않습니다.

## 새 본문과 AI 청크 표시

[외부 텍스트 reveal](../AgentHubChatComposer/external-text-motion.md)은 사용자 채택400ms/ease-out 시각 효과입니다.
본문 전체는 즉시 DOM에 존재하고, textMotion=reveal일 때만 좌→우 soft mask를 적용합니다.
동일 message의 뒤에 붙은 청크는 기존 prefix와 진행 중인 앞 청크를 재시작하지 않으며, 교체·단축·revision 변경은 이전 효과를 취소합니다.
static은 기본값이며 직접 편집·타자 타이머·새 요청·assistant 역할을 추가하지 않습니다. 접근성 공지는 기존 transcript owner에 둡니다.
